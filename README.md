# Giuseppe Angelo – HTML Resume

A personal résumé built with pure HTML and CSS, hosted on GitHub Pages.

## Live Demo

> Once deployed, the resume will be available at:  
> `https://giuseppe68-ai.github.io/html-resume/`

## Project Structure

```
html-resume/
├── index.html          # Main resume page
├── style.css           # Stylesheet
├── assets/
│   └── images/
│       └── Myself.JPG  # Profile photo
└── README.md
```

## Features

- Semantic HTML5 structure
- Centered, print-friendly layout
- Responsive contact bar using CSS Flexbox
- Sections: Professional Summary, Technical Skills, Key Projects, Professional Experience, Education
- External links to LinkedIn profile and employer website

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and content |
| CSS3 | Styling, layout, and typography |

## How to View Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/giuseppe68-ai/html-resume.git
   ```
2. Open `index.html` in any modern web browser — no build step or dependencies required.

## Deploying to GitHub Pages

1. Push all files to the `main` branch of the `html-resume` repository.
2. Go to **Settings → Pages** in the repository.
3. Under **Source**, select `Deploy from a branch`, choose `main` and `/ (root)`, then click **Save**.
4. After a few minutes the resume will be live at the URL shown above.
